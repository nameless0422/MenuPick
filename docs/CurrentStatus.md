### 2026-11-14 로그 위조·알림 주입 차단과 취약점 점검 (운영 배포 2026-11-15)

- **로그 위조 → 운영 알림 주입**을 막았다. 접근 로그가 디코딩된 파라미터 이름을 그대로 찍고
  ERROR 감시가 줄 어디든 ` ERROR `가 있으면 잡아서, 미인증 요청 한 번으로 운영 채널에 가짜 장애
  알림을 띄우고 본문을 고를 수 있었다. 로그 레이아웃이 메시지의 줄바꿈·제어 문자를 이스케이프하고,
  ERROR 감시는 레벨 칸으로만 판정하며, 알림 본문의 멘션을 무력화한다. 근거는 D-078이다.
- **깨진 JSON의 본문 조각**이 파서 메시지를 통해 로그에 남던 것을 없앴다(비밀번호일 수 있다).
- 빌드 플러그인 클래스패스의 `commons-lang3` 3.16.0을 3.20.0으로 올렸다(CVE-2025-48924,
  Dependabot #32). 배포되는 jar에는 원래 들어가지 않는 항목이다.
- web 이미지(nginx alpine)의 `libxslt` 1.1.43-r3에 HIGH 3건(CVE-2026-9947, CVE-2026-87636,
  CVE-2026-125350)이 PR의 이미지 스캔에서 새로 잡혀 수정판(r4)으로 올렸다. 이 서비스는 XSLT를
  쓰지 않아 실제로 닿는 경로는 없다.
- CodeQL 열린 알림 4건은 오탐으로 판단했다 — CSRF 비활성화(#4, Bearer 토큰 + `SameSite=Strict`
  리프레시 쿠키), SSRF(#3, 호스트는 설정 고정이고 사용자 입력은 인코딩된 쿼리 값뿐),
  `Math.random`(#1·#2, k6 부하 테스트 스크립트).
- 그 밖에 확인한 것: npm 감사 0건, 워크플로 액션 전부 SHA 고정, 앱 컨테이너 비루트,
  레이트리밋의 `X-Forwarded-For` 신뢰 홉 처리, nginx 보안 헤더, 요청 추적 ID 형식 검증.
- 로컬 `./gradlew check` 통과. 알림 스크립트는 python3 경로를 가짜 수신기로 확인했고 jq 경로는
  돌려 보지 못해 python3을 우선으로 바꿨다.
- 서버의 `/usr/local/bin/menupick-alert`, `menupick-error-watch`는 2026-11-15에 다시 설치했다.

### 2026-11-07 추가 보안 분석과 인프라 이미지 하드닝 (운영 반영)

- 전수 재점검 + 웹 리서치로 새 취약점을 찾아 둘로 나눠 올렸다(둘 다 머지 전).
  - **인증 메일 탈취(CVE-2019-19844 류)**: `email`·`social_id`가 accent-insensitive 콜레이션이라
    `victim@exámple.com` 변형이 조회에서 victim 행과 매칭되는데 토큰을 입력 주소로 보냈다. 등록된
    `social_id`로만 보내고 NFKC·바이트 동일성 가드를 더해 막았다(D-071).
  - **런타임 이미지 위생**: redis를 EOSL(Alpine 3.21)에서 `8.2-alpine`으로, mysql을 EOL(8.0)에서
    `8.4` LTS로 올리고 digest로 고정, 주간 `infra-image-scan`을 추가했다(D-072). 소스 tarball을
    리포에서 제거했다.
- 안전 확인: 비밀 유출 없음(gitleaks 2건은 테스트 픽스처 JWT, 운영은 전부 env). Spring 2026
  액추에이터·servlet-path CVE는 Boot 4.1.2/Security 7.0.10에서 이미 패치됨.

### 2026-09-13 상황별 빠른 픽 (프리셋)

자주 쓰는 픽 조건에 이름을 붙여 저장하고 다시 실행한다(사용자당 10개). 설계는
[PickPresetDesign.md](PickPresetDesign.md), 결정 근거는 [D-039](DecisionLog.md)·[D-040](DecisionLog.md).

- 저장하는 것은 카테고리·포함 태그·**추가** 제외 태그·거리뿐이다.
- **좌표를 저장하지 않는다.** 거리 기준점은 실행할 때마다 브라우저에서 새로 받는다 —
  회사에서 만든 프리셋을 집에서 눌렀을 때 회사 주변을 뽑지 않기 위해서다.
- **기본 제외 태그를 복사하지 않고** 실행할 때마다 최신 값을 합친다. 프리셋이 기본 제외를
  **해제할 수단은 없다**. 유효 제외가 50개를 넘으면 자르지 않고 409로 멈춘다.
- **참조 태그가 지워지면 실행이 막힌다**(`needsReview`, 버전도 함께 오른다). 사용자가 전체
  조건을 다시 확인해 저장해야 풀린다 — 조건이 조용히 넓어진 채로 추천이 나가지 않게.
- 실행은 전용 경로 `POST /pick/presets/{id}/pick`이고 필터 override를 받지 않는다.
  일반 `POST /pick`의 계약(명시 제외 20 상한, null/빈 배열 의미)과 **쿼리 예산 7/12는 그대로다.**
  빠른 픽 실행은 별도 예산 14로 따로 고정했다.
- `main` 커밋 `c4e0bd7`로 **운영 배포를 완료했다**(2026-09-13).
