
> 2026-08-16 현행화. 실제 이력과 표가 어긋나 있었다 — **두 번째로 많이 쓰인 `fix`가 표에 없었고**, `build`·`form`·`cd`·`release`는 한 번도 쓰이지 않았다. 실제로 쓰는 것만 남긴다.

| 타입             | 설명                                         | 실사용 |
|:---------------|:-------------------------------------------|:----|
| **feat**       | 새로운 기능 추가                                  | 30  |
| **fix**        | 버그 수정                                      | 26  |
| **docs**       | 문서 수정 (README.md, 설계 문서 등)                 | 19  |
| **test**       | 테스트 코드 추가 및 수정                             | 7   |
| **ci**         | CI 설정 수정 (GitHub Actions)                  | 3   |
| **chore**      | 빌드 설정·프로젝트 구조 변경 등 기타 잡무                   | 3   |
| **refactor**   | 동작을 바꾸지 않는 구조 개선                           | 2   |
| **perf**       | 성능 개선                                      | 1   |

표에서 뺀 것들: `style`(포맷팅만 바꾸는 커밋을 따로 만들지 않아 쓰인 적이 없다), `build`·`form`·`cd`·`release`(한 번도 안 씀). `infra`가 초기에 한 번 쓰였지만 이후 `chore`로 수렴했다. 필요해지면 그때 표에 다시 넣는다.

### 범위(scope)

타입 뒤에 괄호로 영향 범위를 적을 수 있다. 어느 영역이 바뀌었는지 제목만 보고 알 수 있을 때만 붙인다.

```text
fix(a11y): h1 계층·선택 상태·폼 초점 복구
```

---

## 작성 규칙
1.  타입 뒤에 `:` 붙여 작성
2.  제목은 50자 이내로 명확하게 요약
3.  마침표 사용안함
4.  명령문을 사용
    * `feat: 메뉴 필터링 기능 구현` (O)
    * `feat: 메뉴 필터링 기능 구현했음` (X)

---

## 커밋 예시 

### **기능 구현 (Feat)**
```text
feat: 메뉴 카테고리별 조회 API 구현
feat: 네이버 지도 API 연동 식당 좌표 저장 기능 추가
```

### **빌드 및 환경 (Build/Chore)**
```text
build: 프로젝트 의존성 QueryDSL 추가
chore: .gitignore 파일에 환경 설정 파일 추가
```

### **문서 작업 (Docs)**
```text
docs: 프로젝트 기획서 및 API 명세서 업데이트
docs: README.md 내 기술 스택 항목 수정
```

### **형식 및 스타일 (Form/Style)**
```text
form: MenuService 클래스 내 메서드 정렬 및 주석 추가
style: 룰렛 결과 노출 화면 애니메이션 속도 조정
```
