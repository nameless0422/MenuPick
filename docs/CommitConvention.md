
| 타입             | 설명                                         |
|:---------------|:-------------------------------------------|
| **feat**       | 새로운 기능 추가                                  |
| **build**      | 빌드 관련 파일 수정 (Gradle, Maven, 환경 설정 등)       |
| **chore**      | 패키지 매니저 설정, 프로젝트 구조 변경 등 기타 잡무             |
| **ci**, **cd** | CI/CD 관련 설정 수정 (Github Actions, Jenkins 등) |
| **docs**       | 문서 수정 (README.md, API 명세서 등)               |
| **form**       | 코드 형식, 정렬, 주석 등 로직 변경이 없는 외형적 수정           |
| **style**      | 코드 스타일(세미콜론 누락, 포맷팅) 혹은 UI 디자인 변경          |
| **test**       | 테스트 코드 추가 및 수정                             |
| **release**    | 버전 릴리즈 관련 커밋                               |

---

## 작성 규칙
1.  타입 뒤에 `:` 붙여 작성
2.  제목은 50자 이내로 명확하게 요약
3.  마침표 사용안함
4.  명령문을 사용
    * `feat: 메뉴 필터링 기능 구현` (O)
    * `feat: 메뉴 필터링 기능 구현했음` (X)

---

## 커밋 예시 

### **기능 구현 (Feat)**
```text
feat: 메뉴 카테고리별 조회 API 구현
feat: 네이버 지도 API 연동 식당 좌표 저장 기능 추가
```

### **빌드 및 환경 (Build/Chore)**
```text
build: 프로젝트 의존성 QueryDSL 추가
chore: .gitignore 파일에 환경 설정 파일 추가
```

### **문서 작업 (Docs)**
```text
docs: 프로젝트 기획서 및 API 명세서 업데이트
docs: README.md 내 기술 스택 항목 수정
```

### **형식 및 스타일 (Form/Style)**
```text
form: MenuService 클래스 내 메서드 정렬 및 주석 추가
style: 룰렛 결과 노출 화면 애니메이션 속도 조정
```
