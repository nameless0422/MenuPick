 
기획서(계속 수정)
---
### 1. 메뉴 및 태그 관리

* **메뉴 CRUD:** 메뉴명 등록, 수정, 삭제 기능.
* **해시태그 시스템:** * 한 메뉴에 다중 태그(#한식, #국물, #해장) 매핑.
    * 기존에 등록된 태그 자동 완성 기능.
* **카테고리 분류:** 대분류(한/중/일/양식 등) 지정 기능.

### 2. 맛집 정보 및 지도 연동 

* **네이버 지도 API 연동:** * 상호명 검색 시 주소, 전화번호, 좌표(위경도) 자동 불러오기.
    * 식당 상세 페이지(네이버 지도 URL) 연결.
* **위치 정보 저장:** 현재 내 위치 기준으로 필터링할 수 있도록 식당의 좌표값 DB 저장.
* **개별 메모:** "여기 돈까스는 소스가 매움" 같은 개인적인 팁 저장.

### 3. 필터링 및 추천 엔진

* **다중 조건 필터:** * `카테고리` + `태그` 중복 선택 (예: 일식 중에서 #면요리만).
    * `포함 태그`와 `제외 태그` 동시 설정.
* **거리 기반 필터링:** * 현재 위치 기준 반경(300m, 500m, 1km) 내 식당이 있는 메뉴만 추출.
* **셔플 & 랜덤 피커 (Front-end):**
    * 백엔드에서 필터링된 **JSON 리스트**를 받아와 프론트에서 랜덤으로 하나를 결정.
    * 재클릭 시 즉시 다른 메뉴를 보여주는 '다시 돌리기' 로직.

### 4. 계정 및 동기화

* **소셜 로그인:** 카카오, 구글 API를 활용한 간편 로그인 (JWT 토큰 발급).
* **데이터 동기화:** 어떤 기기에서 접속해도 내가 저장한 맛집/메뉴 리스트 유지.
* **선호/비선호 설정:** 특정 메뉴를 랜덤 결과에서 아예 제외하거나 가중치를 부여하는 설정.

### 5. 이력 관리 및 UI

* **최근 히스토리:** 최근 일주일간 랜덤으로 뽑혔던 메뉴 로그 기록.
* **공유 기능:** 결과 화면을 이미지로 캡처하거나 텍스트(상호명, 위치)로 카카오톡 공유.
* **랜덤 연출:** 룰렛이 돌아가거나 리스트가 빠르게 지나가는 애니메이션 효과.

| 구분 | 구현 항목 | 비고 |
| :--- | :--- | :--- |
| **Back-end** | RESTful API 설계 (Menu, Restaurant, Tag) | Spring Boot 기반 |
| **DB** | Many-to-Many(N:M) 관계 테이블 설계 | 메뉴 ↔ 태그 매핑 |
| **API 연동** | 네이버 지도 Open API (Search, Map SDK) | 위치 기반 데이터 활용 |
| **Algorithm** | 거리 계산 로직 & 동적 쿼리(QueryDSL) | 하버사인 공식 또는 DB 함수 |
